# Mordparta

Prototype of a true-crime investigation game. You lead a homicide squad: pick leads your operatives offer, read their reports, solve the case within 100 days.

**Play:** open `index.html` in a browser (no server or build needed).

- `PLAN.md` – design plan (⚠ contains spoilers for the demo case).
- `CASE_FORMAT.md` – how to write a case.
